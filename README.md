# ConvoMastery

Online platform for ready-to-use conversational English lesson materials. React (Vite, TypeScript, Tailwind) on the front end, Supabase for accounts, database and files, Stripe for payments, Resend for email.

- `npm install && npm run dev` runs it locally. With no Supabase keys it runs in **demo mode** with sample lessons (logins: `admin@demo.com` / `demo1234`, `teacher@demo.com` / `demo1234`).
- `npm run build:demo` builds a self-contained demo preview.
- See **LAUNCH-GUIDE.md** to go live.
